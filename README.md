# CHEMISTERY · 化学笔记

一本用 LaTeX 写成的化学笔记，`ctexbook` 中文排版，从**化学物理原理**一路写到**分析化学**。

写法上不追求"定义—性质—反应"的罗列，而是尽量回答**"为什么会这样"**：热力学与动力学先讲清判据与速率的来源，元素化学按周期表的电子结构展开，有机化学以机理和合成逻辑为主线，分析化学则把平衡方程组与误差传播算到底。反应式、分子结构与数据表都尽量画成图，公式只承担把图说明白的角色。

## 编译

需要 **XeLaTeX**（TeX Live 或 MiKTeX 完整安装均可）。

```bash
latexmk -xelatex -synctex=1 -auxdir=.build main.tex
```

`-auxdir=.build` 把编译中间产物收进 `.build/`，成品 `main.pdf` 仍出在仓库根（需要 latexmk 4.55 以上；旧版去掉该参数即可，中间产物会落在当前目录）。

不用 `latexmk` 的话，手动跑两遍以生成目录与交叉引用（中间产物落在当前目录）：

```bash
xelatex main.tex
xelatex main.tex
```

产物为 `main.pdf`。用 TeXstudio / VS Code (LaTeX Workshop) 时把编译器设为 `xelatex` 即可。

**依赖宏包**：`ctex`、`amsmath`、`amssymb`、`amsthm`、`graphicx`、`float`、`subcaption`、`hyperref`、`booktabs`、`longtable`、`tikz`（含 `arrows.meta`、`positioning`、`calc` 库）、`mhchem`、`chemfig`。

## 目录结构

```
main.tex        全文（含导言区与全部章节）
main.pdf        编译成品
image/          全部插图，由 main.tex 里的 \includegraphics{image/文件名} 引用
.build/         编译中间产物（.aux / .log / .out / .toc / .xdv 等），可整个删掉重新编译
```

## 说明

- 编译引擎为 **XeLaTeX**：`ctex` 走 xeCJK，比 LuaLaTeX 的 luatexja 每次省约 21 秒固定开销。
- 所有插图集中在 `image/` 目录下，`main.tex` 以 `image/文件名` 引用；改动插图不会自动被 LaTeX 感知，必要时先删旧的 `.aux` 再编。
- 反应式与结构式用 `chemfig` 与 `mhchem` 绘制，键线式反应表按统一几何约定（主链 120° 折线、支链沿分角线）生成。
- 仓库**不含** LaTeX 中间产物（`.aux` / `.log` / `.out` / `.toc` / `.fls` / `.fdb_latexmk` / `.synctex.gz`），也不含 `assets/` 下的原始参考素材，它们由编译或本地材料重新生成。
- 纯黑白排版：正文与公式为黑，页眉页脚与提示性文字为灰，无彩色。
